Tentang Proyek Ini

Kopi Satu Cangkir App dikembangkan untuk menghadirkan pengalaman pemesanan kopi tanpa antrean (*drive-thru / self-pickup*) yang responsif, mengombinasikan tampilan visual yang modern dengan deteksi jarak lokasi gerai kedai terdekat.

Arsitektur Aplikasi & Manajemen State

Aplikasi menggunakan pola arsitektur *Provider* untuk memisahkan logika bisnis dari komponen UI widget Flutter. Alur pemesanan produk, penyesuaian varian gula/susu, hingga pemilihan gerai diproses secara reaktif tanpa penurunan kecepatan render.

Arsitektur Sistem Mobile

Flutter App → Provider memproses state → Geolocation mendeteksi gerai terdekat → REST API mencatat transaksi → Barcode antrean penerimaan siap di-scan di kasir gerai.

Keputusan Desain & Trade-off

📱 Single Codebase Flutter

Memungkinkan efisiensi pengembangan lintas platform Android dan iOS dengan satu basis kode Dart tanpa harus mengelola dua repositori terpisah.

⚡ State Management Provider

Provider dipilih karena bobotnya yang ringan dan integrasinya yang sangat alami dengan siklus hidup widget Flutter untuk aplikasi pemesanan berskala menengah.

Tumpukan Teknologi

Flutter Dart Provider REST API Geolocation

Yang Berhasil Dicapai

  • Performa rendering grafis antarmuka yang sangat mulus di angka 60 FPS pada perangkat seluler.
  • Fitur deteksi lokasi gerai terdekat dengan penghitungan jarak kilometer secara real-time.
  • Alur pemesanan singkat 3 langkah (*Pilih Menu → Pilih Gerai → Ambil Pesanan*).
