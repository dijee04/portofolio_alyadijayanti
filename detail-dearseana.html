Tentang Proyek Ini

DearSeana Bakery Store dibangun untuk menyelesaikan tantangan toko kue independen yang ingin beralih dari pemesanan pesan singkat (WhatsApp manual) menuju alur transaksi otomatis berbasis web secara penuh tanpa campur tangan admin saat verifikasi pembayaran.

Alur Transaksi & Payment Gateway

Sistem menghubungkan keranjang belanja pelanggan dengan API MidTrans Snap Popup. Begitu transaksi dikonfirmasi di sisi bank atau QRIS pelanggan, server webhook MidTrans mengirimkan notifikasi terenkripsi dengan Signature Key SHA-512 untuk memperbarui status pesanan menjadi 'Terbayar' secara *real-time*.

Arsitektur Sistem

Pelanggan melakukan checkout → Server membuat Snap Token → MidTrans memproses pembayaran → Server menerima Webhook notifikasi SHA-512 → Status transaksi terupdate di database MySQL.

Keputusan Desain & Trade-off

💳 MidTrans Snap Popup vs Core API

Dipilih Snap Popup karena menyajikan antarmuka pembayaran lengkap (Bank Transfer, QRIS, GoPay) tanpa harus membangun formulir pembayaran kartu kredit dari awal, menjaga kepatuhan PCI-DSS.

🔐 Verifikasi SHA-512 Signature

Setiap notifikasi webhook dipastikan keasliannya dengan menghitung ulang kombinasi order_id + status_code + gross_amount + server_key untuk mencegah pemalsuan callback.

Yang Berhasil Dicapai

  • Otomasi penuh proses konfirmasi pembayaran tanpa perlu verifikasi bukti transfer manual lewat pesan singkat.
  • Waktu pemrosesan pesanan berkurang dari rata-rata 15 menit menjadi kurang dari 10 detik setelah transaksi berhasil.
  • Dashboard manajemen produk & stok yang responsif bagi pemilik toko kue.
