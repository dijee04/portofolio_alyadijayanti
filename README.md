## ✨ Fitur Utama

- **Desain Modern & Interaktif**: Menggunakan kombinasi warna kontras (tema gelap dan aksen neon) dengan aset dekoratif piksel melayang yang dapat berinteraksi dengan kursor (*drag-and-drop*).
- **Animasi Super Halus**: Dilengkapi dengan teks *marquee* berjalan, kartu profil 3D yang dapat dibalik (flip card), efek sorotan (*hover state*) yang hidup, serta visualisasi aktivitas kontribusi GitHub buatan (*mockup*).
- **Struktur Kode Rapi (*Clean Code*)**: Struktur HTML semantik, gaya desain (*styling*) CSS Vanilla yang terorganisir, serta modularitas yang memudahkan pemeliharaan kode (*maintainability*).
- **Tata Letak Responsif**: Tampilan sudah disesuaikan agar berjalan optimal di berbagai ukuran layar (Desktop, Tablet, dan Seluler).

## 🚀 Panduan Menjalankan Secara Lokal

Karena proyek ini merupakan situs web statis murni tanpa basis data (*database*) atau *backend* khusus, Anda dapat menjalankannya dengan sangat mudah:

1. **Kloning (*Clone*) repositori ini:**
   ```bash
   git clone https://github.com/username-anda/nama-repo-portofolio.git
   ```
2. **Buka folder proyek:**
   ```bash
   cd nama-repo-portofolio
   ```
3. **Jalankan peladen lokal (*local server*):**
   Anda bisa menggunakan ekstensi *Live Server* di VS Code, atau menjalankan perintah Python sederhana:
   ```bash
   # Jika menggunakan Python 3
   python -m http.server 8000
   ```
4. Buka peramban (*browser*) web Anda dan akses `http://localhost:8000/`.
